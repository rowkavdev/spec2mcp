# notes-api - MCP server for Notes API

Generated by [spec2mcp](https://github.com/rowkavdev/spec2mcp) from the Notes API OpenAPI spec (API version 1.0.0). Exposes 4 tools over stdio or Streamable HTTP.

## Run

```bash
npm install
cp .env.example .env  # fill in your credentials, then export or source it
npm start  # stdio (default)
PORT=3000 npm run start:http  # Streamable HTTP at http://127.0.0.1:3000/mcp
```
The HTTP endpoint listens on localhost only. Keep it private; it has no client authentication.

## Claude Desktop

```json
{
  "mcpServers": {
    "notes-api": {
      "command": "node",
      "args": ["/absolute/path/to/server.mjs"],
      "env": {
        "NOTES_API_BEARER_AUTH": "..."
      }
    }
  }
}
```

Settings are saved in `spec2mcp.config.json`. The server reads the name, base URL and filters at startup. To add back operations excluded at generation, regenerate the project.

| `get_note` | GET /notes/{noteId} | GET /notes/{noteId} |

## Auth

- `NOTES_API_BEARER_AUTH` - bearer (scheme `bearerAuth`)

Base URL: `https://api.notes.example/v1` - override with `NOTES_API_BASE_URL`.
