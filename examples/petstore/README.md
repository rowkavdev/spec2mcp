# pet-store - MCP server for Pet Store

Generated by [spec2mcp](https://github.com/rowkavdev/spec2mcp) from the Pet Store OpenAPI spec (API version 1.0.0). Exposes 4 tools over stdio or Streamable HTTP.

## Run

```bash
npm install
npm start  # stdio (default)
PORT=3000 npm run start:http  # Streamable HTTP at http://127.0.0.1:3000/mcp
```
The HTTP endpoint listens on localhost only. Keep it private; it has no client authentication.

## Claude Desktop

```json
{
  "mcpServers": {
    "pet-store": {
      "command": "node",
      "args": ["/absolute/path/to/server.mjs"]
    }
  }
}
```

Settings are saved in `spec2mcp.config.json`. The server reads the name, base URL and filters at startup. To add back operations excluded at generation, regenerate the project.

## Tools

| Tool | HTTP | Description |
| --- | --- | --- |
| `list_pets` | GET /pets | List all pets in the store, optionally filtered. |
| `create_pet` | POST /pets | POST /pets |
| `get_pet` | GET /pets/{petId} | GET /pets/{petId} |
| `delete_pet` | DELETE /pets/{petId} | DELETE /pets/{petId} |

Base URL: `https://api.petstore.example/v1` - override with `PET_STORE_BASE_URL`.
